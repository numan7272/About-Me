# Lebenslauf

`cv.html` ist ein eigenständiger, ATS-tauglicher Lebenslauf (eine Spalte,
Standard-Schrift, echter Text — keine Grafiken-als-Text).

**Bewusst NICHT unter `public/`** abgelegt, damit er nicht automatisch
mit der Website deployt und öffentlich indexierbar wird (DSGVO + die im
ContactPanel dokumentierte Praxis „Lebenslauf auf Anfrage").

## PDF erzeugen
1. `cv.html` im Browser öffnen
2. `Strg/Cmd + P` → Ziel „Als PDF speichern"
3. Ränder „Standard", Hintergrundgrafiken aus

## Vor dem Versenden ausfüllen (gelb markiert)
- Telefonnummer
- Portfolio-Link (deine Domain)
- ggf. weitere Sprachen (z. B. Türkisch)
