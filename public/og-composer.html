So speicherst du das OG-Image:
1. Rechtsklick auf die schwarze Card unten → "Element untersuchen"
2. Im DevTools rechtsklick auf <div class="og"> → "Capture node screenshot"
3. PNG wird auf den Desktop gespeichert
4. Umbenennen zu og-image.png, dann nach public/og-image.png kopieren
Alternative: Browser-Fenster auf exakt 1200px breit, dann Screenshot der Card.
